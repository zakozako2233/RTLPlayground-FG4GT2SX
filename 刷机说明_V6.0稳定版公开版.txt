【怎么选刷法】
  ● 第一次刷（原厂是傻瓜交换机，没有网页管理）→ 必须用【编程器】刷
  ● 已经刷过本固件、想升级新版 → 网页在线升级即可

【方式一：编程器首次刷机（必读）】
  准备：CH341A 编程器（或同类 SPI 编程器）、SOIC 测试夹/插座、配套软件（AsProgrammer / NeoProgrammer 等）
  1. 断电，拆下外壳，找到 4MB SPI Flash 芯片（P25Q32SH / W25Q32 等，丝印多为 32M 位）
  2. 编程器连接芯片（SOIC 夹免拆夹上，或取下芯片放入插座）
  3. 先【读取并保存原厂固件】备份——变砖时直接写回即可恢复
  4. 擦除整片 → 写入本 bin（从 Flash 起始地址 0x000000 开始）→ 校验一致
  5. 断电取下编程器，装机通电
  6. 电脑网线连任一电口，浏览器访问 http://192.168.3.247，密码 admin 登录即完成
  说明：512KB 固件从 Flash 起始地址写入即可，无需 4MB 整片镜像。

【方式二：网页在线升级（已刷过本固件的用户）】
  1. 电脑连交换机任一电口，浏览器访问 http://192.168.3.247
  2. 输入密码 admin 登录（账号留空）
  3. 进入"系统/升级"页面，选择本 bin 文件上传
  4. 等待 30~40 秒，校验通过自动重启（约 1~3 分钟恢复）
  5. 刷新页面即完成

【登录信息】
  地址: http://192.168.3.247
  密码: admin（公开版本通用密码，账号留空）

【安全提醒】
  公开版默认密码为 admin，登录后建议立即修改。
  刷机/写片过程切勿断电；万一变砖，用编程器重写原厂备份即可恢复。
