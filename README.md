# 睿颖 FG-4GT-2SX 定制管理固件（基于 RTLPlayground 二次开发）

> 为**睿颖（RUIYING）FG-4GT-2SX** 2.5G 交换机深度定制的全中文图形化管理固件。
> 底层基于开源项目 **RTLPlayground**（[github.com/logicog/RTLPlayground](https://github.com/logicog/RTLPlayground)）二次开发，在保留原项目全部能力的基础上，**重写网页界面、新增安全与实用功能、修复硬件灯语**，并针对 4MB Flash 与 8051 处理器做了性能优化。

---

## 为什么推荐它（强推理由）

| 亮点 | 说明 |
|---|---|
| **全网口 2.5G 全速率** | 4×2.5G 电口 + 2×SFP，不再受 1G 网管交换机的带宽瓶颈 |
| **全中文、小白可懂** | 图形化网页，电脑版 / 手机版自适应，每一项都有通俗说明 |
| **静态链路聚合（XOR）** | 两条线路聚合成最高 5G 吞吐，断线自动降级单线路继续工作 |
| **主页实时 CPU 占用** | 浏览器直接看交换机 CPU 负载，仅内存计算、不写闪存 |
| **安全防护齐全** | 登录防爆破（5 次锁 60 秒）、会话超时、命令注入防护、CSP |
| **零占用开关** | ACL / 风暴抑制 / NTP 都带独立开关，**关闭时完全不占性能** |
| **灯语实测修复** | 电口绿灯标准 link/act（链路常亮、流量闪烁），黄灯标识 2.5G |
| **4MB 极省空间** | 手机 / 电脑界面二选一加载，固件仅 512KB，留足配置空间 |

> 把一台不到百元的**非网管交换机**变成**带 ACL、聚合、NTP、监控的全能管理交换机**，这是本固件存在的意义。

## 功能总览（V5.9 最新版）

### 管理界面
- 全中文图形化网页，浅灰清爽 UI，电脑 / 手机按设备自动二选一加载（不同时渲染，省 8051 性能）
- 主页实时显示 **CPU 占用率**（内存计算，**不写入闪存**，零磨损）
- 页面底部开发者署名：**zakozako2233**

### 网络功能
- **静态链路聚合（XOR）**：支持 4 个聚合组、多口组合，聚合口**断线自动降级**为单线路继续工作
- **端口管理**：逐口查看速率协商、收发计数、自协商设置、EEE、MTU
- **VLAN / 镜像 / IGMP 组播 / 生成树（STP）**：完整保留 RTLPlayground 原生能力

### 安全功能
- **登录防爆破**：连续输错 5 次锁定 60 秒，锁定期拒绝一切尝试（HTTP 429），页面倒计时
- **会话超时**：5 分钟无操作自动退出
- **命令注入防护**：命令行接口 32 行上限、特殊字符过滤、路径穿越拒绝
- **ACL 访问控制**（带开关，关闭零占用）：按源 / 目的地址做转发控制

### 附加功能（均带独立开关）
- **风暴抑制**：广播 / 组播 / 未知单播风暴抑制，关闭时零性能占用
- **NTP 时间同步**：自动对时，关闭时零性能占用
- **固定 IP**：192.168.3.247，重启不丢失

### 硬件灯语（实测修复）
- 绿灯：链路建立**常亮**，有数据传输**闪烁**（标准 link/act）
- 黄灯：**2.5G** 链路点亮，1G / 低速不亮黄灯
- 电源灯、SYS 状态灯：保持原厂逻辑，未改动

## 刷机方法

1. 电脑网线连接交换机任一电口
2. 浏览器访问 `http://192.168.3.247`
3. 输入密码 `admin` 登录（账号留空）
4. 进入「系统 / 升级」页面，选择本固件 `.bin` 文件上传
5. 等待 30~40 秒，校验通过后自动重启（约 1~3 分钟恢复）
6. 刷新页面即完成

> ⚠️ 刷机过程中请勿断电，否则可能变砖。建议刷机前用编程器/SOIC 夹备份原厂 Flash。

## 常见问题

- **LACP 为什么不行？** RTL8372N 硬件对 LACP 协议帧（01:80:C2:00:00:02）做硬过滤，LACP 无法在该芯片实现。本固件使用 **XOR 静态聚合**：NAS / PC 侧选择静态 / XOR 模式即可
- **聚合跑不满怎么办？** 聚合按流哈希分配，单条连接只走一条物理链路。需要**对端也双口聚合** + **多线程测速**（如 `iperf3 -P 4`）才能跑近 5G；哈希默认全字段（MAC+IP+端口）已是最分散配置
- **SFP 光口？** 插标准千兆 / 2.5G 模块即可用（默认行为）
- **闪存寿命？** 配置仅在保存时写入，日常运行零写入；本固件 CPU 占用等监控数据仅存内存
